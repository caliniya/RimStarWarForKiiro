## 机械族（Mech）源码调研（只调研，未写任何代码）

参考资料：`D:\project\RimWorld-Source-1.6`（反编译）、`E:\app\rimworld\RimWorld16\Data`（官方 Defs）。

伤害/反机械相关结论：
- `ArmorUtility.GetPostArmorDamage`：**`damageDef.armorCategory == null` 时直接跳过全部护甲**（含衣物+本体）
  —— 纯 XML 就能做「无视护甲」的伤害类型（但对所有人一视同仁，非机械专属）。
- `DamageWorker.Apply(DamageInfo, Thing)` 是 public virtual，`DamageInfo` 是结构体按值传参，
  所以自定义 `DamageWorker` 子类在 Apply 里判 `pawn.RaceProps.IsMechanoid` 后改 `SetAmount`
  是**最干净的反机械乘倍钩子**，XML 里 `DamageDef.workerClass` 指定即可，**无需 Harmony**。
  （注意不要只覆写 `ApplySpecialEffectsToPart`，它在 AllowDamagePropagation=false 时不会被调用。）
- `StunHandler.CanBeStunnedByDamage`：硬编码只有 `Stun` / `EMP`(非血肉) / `MechBandShockwave`(机械)
  / `NerveStun`(非机械) 能致晕 → **自定义 DamageDef 无法致晕**，要嘛复用 EMP，
  要嘛在自己的 DamageWorker 里手动 `pawn.stances.stunner.StunFor(...)`。
  眩晕时长 = `dinfo.Amount * 30` tick，或被 `constantStunDurationTicks` 覆盖；
  受 `stunResistStat`(EMPResistance) 缩减、受 `stunAdaptationTicks`(EMP 为 2200) 的适应性限制。
- `DamageDef.externalViolenceForMechanoids`：决定打机械是否算「外部暴力」（触发 IsColonist 保护/PlayWoundedVoice）。
- EMP 无 armorCategory ⇒ 不吃护甲；对机械师的水和指控有独特密封。
- `ProjectileProperties.GetArmorPenetration`：`damageDef.armorCategory == null` 时直接返回 0（面板上穿甲显示为 0）。

机甲基座（做新机械体的最小套路）：
- 继承链 `BasePawn` → `BaseMechanoid`（Core\Defs\ThingDefs_Races\Races_Mechanoid.xml）→
  `BaseMechanoidWalker` / `MechCentipede` / `SuperHeavyMechanoid`。Biotech 的
  `LancerMechanoidWalker`、`Light/Medium/Heavy/SuperHeavyMechanoid` 都是可直接 ParentName 的抽象父级。
- 必填：`race.body`（现成 Def 可复用：Mech_Light / Scorcher / Mech_Centurion / Apocriton /
  Mech_Diabolus / Mech_Warqueen / Mech_Tunneler / MechanicalCentipede / Lancer / Mech_Agrihand）、
  `race.mechWeightClass`、`race.lifeStageAges`(MechanoidFullyFormed)、
  `butcherProducts`（`RaceProperties.ConfigErrors` 强制：机械必须写 butcherProducts）。
- 可选强化件：`CompProperties_Shield`(EnergyShieldEnergyMax/RechargeRate)、
  `CompProperties_ProjectileInterceptor`(连射拦截护盾，有 disarmedByEmpForTicks)，
  `CompProperties_TurretGun`(移动炮塔)、`PawnKindDef.abilities`、`PawnKindDef.isBoss`、
  `CombatPower`、`DetritusLeavings`。
- 可由机械师指挥的前提：`EverControllable()` == 有 `CompOverseerSubject`（BaseMechanoid 自带），
  带宽 `BandwidthCost`、占用时间 `ControlTakingTime`；充电要有 `mechWeightClass` 且
  充电机 `building.requiredMechWeightClasses` 包含它（BasicRecharger 只 Light；StandardRecharger 含 UltraHeavy）。
- `MechWeightClassDef` 只有 Light/Medium/Heavy/UltraHeavy(UltraHeavy.canResurrect=false)。

出场途径（关键，别漏）：
- 敌对袭击：Core `FactionDefs\Factions_Hidden.xml` 里 `Mechanoid` 派派的 `pawnGroupMakers.options`
  **写死了具体 PawnKindDef 清单**，新增机械体必须靠 `Patches/` 下的 PatchOperationAdd 加进去
  （本工程 `Patches/` 目录已存在且为空，正是为此准备的）。
- 机械集群：`MechClusterGenerator.MechKindSuitableForCluster` 按 IsMechanoid && !isGoodBreacher &&
  isFighter && !allowInMechClusters 自动纳入 ⇒ **默认自动参与**，不想出现就设 `<allowInMechClusters>false</allowInMechClusters>`。
- 玩家侧：`RecipeDef ParentName="BaseMechanoidRecipe"`（在 Biotech\Defs\RecipeDefs\Recipes_MechGestator_Light.xml）
  → Light/Medium/Heavy/SuperHeavy 四个抽象层订食材与研究前提；products 指向自己的 ThingDef 即可。
